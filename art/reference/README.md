# Reference images

Images generated from the prompts in [`art/reference-prompts`](../reference-prompts/README.md), used as references for the Blender scenes and animations. Each prompt has a fixed file name and folder; the prompt sheet shows both, with copy buttons.

| Folder | Images |
| --- | --- |
| [`style/`](style/README.md) | Start here: 3 |
| [`characters/`](characters/README.md) | Characters: 7 |
| [`poses/`](poses/README.md) | Animation poses: 10 |
| [`props/`](props/README.md) | Ball, goal and pitch: 4 |
| [`arena/`](arena/README.md) | Arena and cameras: 4 |
| [`moments/`](moments/README.md) | Moments: 4 |
| [`textures/`](textures/README.md) | Textures: 4 |
| [`worlds/`](worlds/README.md) | Eras and Classics: 7 |

- Name each file exactly as listed, e.g. `C01-kicker-turnaround.png`. Alternatives get `-v2`, `-v3`.
- To add images on GitHub, open the folder and use **Add file → Upload files**. Or attach them in the chat with Claude, who files them.
- Keep whatever extension the download has (`.png`, `.jpg` or `.webp`).

This folder is generated by `node art/reference-prompts/build.mjs`; edit the prompts there.
